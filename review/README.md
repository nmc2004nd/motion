# Core review UI

Mini app HTML tĩnh để ôn tập hai tài liệu:

- `docs/core_algorithms.md`
- `docs/CORE_ARCHITECTURE_AND_DEFENSE.md`
- `docs/force_poly_algorithms.md`
- `docs/FORCE_POLY_ARCHITECTURE_AND_DEFENSE.md`
- `docs/force_model_algorithms.md`
- `docs/FORCE_MODEL_ARCHITECTURE_AND_DEFENSE.md`
- `docs/force_cnn_algorithms.md`
- `docs/FORCE_CNN_ARCHITECTURE_AND_DEFENSE.md`
- `docs/SLIP_V1_ARCHITECTURE_AND_DEFENSE.md`

Mở trực tiếp:

```bash
xdg-open review/index.html
```

Nếu không dùng GUI từ terminal, mở file `review/index.html` trong trình duyệt.

Nội dung chính:

- Học theo module: preprocessing, detection, tracking, visualization, architecture, force_poly, force_model, force_cnn, slip_v1.
- Flashcard có lưu tiến độ bằng `localStorage`.
- Quiz nhanh.
- Playground tham số để nhớ trade-off khi tăng/giảm config.
- Danh sách câu hỏi phản biện có lọc từ khóa.
